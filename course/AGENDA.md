# 90-minute Git Crash Course (Student Repo)

- 0-10 min: Setup (Git config, clone, branch)
- 10-25 min: Git basics (status, add, commit, log, branch, push)
- 25-45 min: Pair feature work in `game/`
- 45-60 min: PRs and reviews
- 60-80 min: Merge conflicts (`course/conflict_playground.txt`)
- 80-90 min: Wrap-up and run `python main.py`
