# Exercises (Student Repo)

1) Setup (10 min)
- Configure Git, clone, create `group0X/warmup`

2) Basics (15 min)
- Edit `game/ui.py` (header function TODO), commit, push, PR

3) Pair Feature (20 min)
- Implement your module TODOs

4) Collaborate (15 min)
- Pull latest, fix minor conflicts, re-push

5) Merge Conflicts (20 min)
- Everyone edits first line of `course/conflict_playground.txt`, resolve

6) Release (10 min)
- Tag `v0.1`, run `python main.py`
